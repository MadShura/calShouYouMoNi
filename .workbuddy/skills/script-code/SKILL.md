# 脚本编写规范

## 明确脚本目的

- 一般的测试脚本：用于定位bug 核查错误的脚本：**脚本本身必须用 `_gen` 前缀**命名，**定位完毕后必须删除**脚本与产物，禁止残留在项目目录内。
- 非一般的脚本，而是用户要求的脚本：脚本位置**必须**在项目目录 `scripts` 内。
- 任何的脚本,只要有生成物，必须使用 `_gen` 前缀命名。除非这个生成的文件是需要被打包的正式产物。
- **禁止**生成`_gen`前缀的目录
