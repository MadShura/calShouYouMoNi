## 0. 乘区顺序（先看这个）

```text
伤害 = ATK × K(DEF_eff) / 100 × 随机(0.95,1.05)
       × Π(100 + p_i) / 100        ← 本文所有 p_i 都在这里，逐个连乘
       × (暴击 ? 暴伤/100 : 1)
       × (100 + 伤害加成) / 100
       × (100 - min(目标减伤,80)) / 100
```

- `p_i` 之间是**连乘**：+100% 和 +100% = ×4，不是 +200%。
- `K` 的区间是 2 ~ 约248，`ATK ≥ 3×DEF_eff` 时硬切成 100（跨过 3 倍会掉档）。
- 命中率/暴击率在伤害前判定，封顶 100%。

## 6. 场景敌人的命中/闪避（用于西行/神鬼）

### 6.1 通天塔（地图 5）

- 敌人构造是 `new Character_Enemy(品质, GetTrueRound(), 预设, 地图, CurRound)`，即 `_level = 层数×16+1500`、`True_Round = 层数`
- 命中 = 闪避 = 暴击 = 抗暴 = `min(层数/100,70) + max(0,(层数−11000)/1000)`
- 速度 = `26 + 品质 + 1 + 层数/100 + min(层数/100,70)`；品质 1 小怪 / 2 精英 / 3 首领
- 例：第 1000 层 → 10；第 10000 层 → **70**；第 20000 层 → 79；第 100000 层 → 159
- 数值统一由 `enemy-stats.ts` 计算，结果见 `output/敌人属性.md`

### 6.2 试炼

- 敌人是按层数升级的英灵（`ShiLian_Manger.GetCurCengShuYingLinglist`）
- 目标等级 = `10000 + (层数 − 1) × 250 × (层数/10 + 1)`
- `LevelToTargetLevel` 会重写属性：
  - 生命：`PercentAddition = 1,000,000 + 层数×10,000`
  - 攻击/防御/穿透：`PercentAddition = 10,000 + 层数×500`
  - 命中/闪避/暴击/抗暴/暴伤/连击/反击/伤害加成/减伤/幸运：`Base_Value = 100 + 层数×3`（固定值，不再是 5）
  - 速度：`Base = 层数×35`，`Percent = 50 + 层数`
- **试炼 100 层**：命中/闪避/暴击/抗暴 = **400**，减伤 400（封顶 80），速度 3500×2.5 = 8750
- 我方命中 113、闪避 98 → 命中率 `(100+113−400+1)/101` 为负 → **0% 命中**；神鬼志异也因闪避低于敌命中而 0

### 10.1 司马懿增伤链路（逐行核对）

1. 关羽1技能开战给全体敌人 +3 威慑；神转职再 +3。同类威慑会合并成 1 条，**Level=6**。
2. 司马懿神转职在开战时给全体友军挂一条「每层威慑 +10% 伤害」的光环；魔转职没有这条。
3. 攻击结算顺序（`Action_CommonAttack.Excute`）：命中/暴击判定 → 攻击时乘区 → 最终伤害。
4. 这条光环在每次攻击时加：目标威慑层数 × 10 = 6×10 = 60，作为独立乘区 ×1.60。
5. 司马懿3技能同样 +60；两个来源各 ×1.60，连乘 **1.6×1.6=2.56**（神转职自身）。
6. 最终伤害里每条来源都逐个 ×(100+p)/100，所以每个来源是独立乘区，不是加在一起。
7. 魔转职：没有那条光环，只有3技能 ×1.6；但魔转职额外 +20% 且普攻变全体，所以司马懿做输出位时魔转职更强。

### 10.2 转职

每个英灵魔/神二选一（`YingLing_SettingData.GetSkill(ZhiYe)`），不能同时生效。`yingling-output.ts` 把魔转职与神转职分别作为候选枚举；做队友时若两个转职都有团队效果，取收益更高的那个。

### 10.3 为什么是连乘而不是加算（以司马懿 ×3.494 为例）

`Damage_Recorder.CulFinalDamage` 的顺序是：

```text
伤害 = 攻击 × K/100 × Π(100 + 各来源p)/100 × (100 + 伤害加成)/100 × (100 - min(减伤,80))/100
```

两个“桶”：

- **攻击桶**：面板攻击% + 武松神转职的 +20%，先算攻击，再进 K。
- **伤害加成桶**：面板伤害加成 + 武松3技能的 +35%，加法合并后只乘一次。

其余每一条独立乘区（技能倍率、后羿弓、威慑、魔转职、魅惑、怯懦、神通27、羁绊）各自 ×(100+x)/100 后连乘。

按源码核对后，技能倍率本身也可能是多条独立乘区：

- 司马懿普攻：2技能先 `-20`，魔转职再 `+20` → `0.8×1.2=0.96`（不是描述里的 100%+20%）。
- 公孙胜普攻：2技能先 `-10`，魔转职再 `+20` → `0.9×1.2=1.08`。
- 孙悟空怒气：1技能在没有魔转职时 `-30`；魔转职满怒 → 100%（不是 70%×1.3）。
- 荆轲怒气：1技能是 `300×num/目标数-100`，5 目标=60%/目标（不是 300%）。
- 二郎神怒气：1技能在魔转职时 `-20-15=-35` → 65%（不是 100%）。

以 公孙胜魔转职·普攻（队伍 `[1,2,6,7,10]`）为例代入：

```text
攻击桶   (100+0+20)/100 = 1.200
技能     公孙胜2技能 -10 → 0.9；公孙胜魔转职 +20 → 1.2；合计 1.080
后羿弓                   = 0.800
司马懿神转职 全队威慑 6层×10%=60 = 1.600
公孙胜3技能 自身怯懦 2层×15%=30 = 1.300
神通27 6威慑+2怯懦=8层  = 1.080
羁绊                     = 1.000
伤害加成桶 (100+0+35)/100 = 1.350
总倍率 = 1.2×1.08×0.8×1.6×1.3×1.08×1.0×1.35 = 3.144
```

所以不是 `80% + 35% + 20% = 135%`；后羿弓、技能、威慑、魔转职等各乘一次，35% 只和伤害加成同桶相加。
