# finalCal — 逐小时大循环:挂机收益与终局第 5 层判定

## 1. 计算口径与公式来源
- 逐小时大循环(finalcal.md):去掉 BASE_HOURS/二分,前置固定推层路线(为春秋蝉最大利用率),上移整数小时后逐小时行动,第一次满足三条件即跳出。
- 前置推层:1图→100层 → 2图→100层 → 3图→100层 → 4图→10000层 → 5图→100层 → 1图→1000层 → 2图→10000层 → 3图→10000层 → 5图→一直打;每步 sec/层算实际时间(孙悟空 1.1s、云霄 0.85s,余数单独记录确保准确)。
- 前置抽奖:1000抽Lv1、4000抽Lv3、5000抽Lv4、20000抽Lv5、20000抽Lv5;奖池权重期望来自游戏目录 JiangChi_Data_Json.txt(6级).
- 每小时:任务奖励(4h刷新,配置不可得部分说明)/点卡(每1h净赚38.5万钱币)/元宝购物(8h与10h结算点核查)/抽奖(8h,两组选期望高)/阵营(8h)/寻宝(10h)/地图掉落/扫荡(每1h判定,不能秒杀时春秋蝉1个=1h)/物资转面板/三条件判定.
- 购物正反馈:攒够整组买4翅膀(各2个/48888)+孟婆汤(2个/46888够转生不买)+藏宝图(1个/25888满974不买);翅膀买了立即升级,寻宝大奖+5%/级、阵营+5%/级、装备四维75+25L,剩余元宝升VIP.
- 抽奖券(prop10)只从地图/扫荡掉落产出;寻宝10h一轮(源码 RefreTime_min*60=36000s,非 Time_Per_Round),每格固定256万×权重‰(藏宝图补满必掉)×翻倍期望.
- 寒铁打造按时间串行:单件 min(30秒,3+0.2×炼器级);神兵默认23件全解锁;突破先堆幸运5W确保掉落100%.
- 三条件:命中100% + 速度更快 + 一击必杀(伤害≥敌HP);任务奖励道具配置不在工作区,仅计可确定骨架.
- 队伍:各组队内 三藏/沙僧/八戒/神林冲 提供西行羁绊;命中/攻击/伤害的英灵技能乘区按组(悟空走人皇印链,云霄走普攻80%链)。神林冲无独立面板加成配置,其间接效果并入西行羁绊口径,不单列.
- 资源分配架构:大循环与伤害链通用;每组自带 allocate 方法决定余下突破投幸运/攻击/穿透/速度。组1悟空天覆突破幸运(补速后余下全幸运走命中链);组2云霄天覆突破攻击;组3云霄天覆突破穿透;组4云霄鸟翔突破速度(速度差转增伤,速度到顶金币只换灵纹).
